# 项目结构文档

## 1. 项目基本信息

- **项目名称**: 敬言馆主

## 3. 主要文件功能

### 3.1 配置文件

- **_config.yml**: 主配置文件，包含站点基本信息、URL 设置、目录配置、写作设置、分页设置等
- **_config.shoka.yml**: shoka 主题配置，包含菜单设置、社交链接、颜色配置、评论设置等
- **_config.landscape.yml**: landscape 主题配置（未使用）

### 3.2 依赖管理

- **package.json**: 定义项目依赖和脚本，包含 Hexo 核心及插件
- **package-lock.json**: 锁定依赖版本

### 3.3 主题文件

- **themes/shoka/layout/**: 包含所有页面模板
- **themes/shoka/source/css/**: 主题样式文件
- **themes/shoka/source/js/**: 主题 JavaScript 文件
- **themes/shoka/scripts/**: 主题脚本文件

### 3.4 内容文件

- **source/_posts/**: 文章目录，按分类组织
- **source/friends/**: 友链页面
- **source/webstack/**: 资源栈页面
- **source/zishe/**: 子页

## 4. 技术栈

- **静态站点生成器**: Hexo 6.3.0
- **主题**: shoka
- **语言**: Markdown
- **样式**: Stylus
- **模板**: Nunjucks (njk)
- **部署**: GitHub Pages

## 5. 核心功能

- **文章管理**: 支持分类、标签、归档
- **评论系统**: Valine
- **搜索功能**: Algolia
- **响应式设计**: 适配不同设备
- **PWA 支持**: Service Worker
- **社交链接**: 支持 GitHub、音乐、邮件等
- **友链页面**: 展示友情链接
- **资源栈页面**: 展示资源收集

## 6. 部署流程

1. **本地开发**: `npm run server`
2. **构建静态文件**: `npm run build`
3. **部署到 GitHub Pages**: `npm run deploy`

## 7. 项目特点

- **模块化结构**: 清晰的目录组织
- **主题定制**: 支持自定义样式和配置
- **性能优化**: 支持资源压缩和 Service Worker
- **扩展性**: 丰富的插件生态
- **多语言支持**: 支持中英文等多种语言
