# 网站优化方案

## 1. 图片优化方案

### 1.1 图片压缩

**具体措施**：
- 使用在线工具如 TinyPNG、CompressJPEG 等压缩现有图片
- 对于二维码图片（alipay.png、wechatpay.png、paypal.png），可以使用更高的压缩率
- 对于头像图片（avatar.jpg），可以适当降低分辨率和质量

**预期效果**：
- 图片大小减少 50-70%
- 首屏加载时间显著缩短

### 1.2 图片格式转换

**具体措施**：
- 将图片转换为 WebP 格式，这是一种现代图片格式，比 JPEG 和 PNG 更小
- 使用 `<picture>` 标签提供多种格式的图片，让浏览器自动选择最适合的格式

**代码示例**：
```html
<picture>
  <source srcset="image.webp" type="image/webp">
  <source srcset="image.jpg" type="image/jpeg">
  <img src="image.jpg" alt="Description">
</picture>
```

### 1.3 图片懒加载

**具体措施**：
- 实现图片懒加载，只加载可视区域内的图片
- 使用 Intersection Observer API 实现高效的懒加载

**代码示例**：
```javascript
// 图片懒加载
const lazyImages = document.querySelectorAll('img[data-src]');

const imageObserver = new IntersectionObserver((entries, observer) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      img.classList.remove('lazy');
      imageObserver.unobserve(img);
    }
  });
});

lazyImages.forEach(img => imageObserver.observe(img));
```

### 1.4 响应式图片

**具体措施**：
- 使用 `srcset` 和 `sizes` 属性提供不同分辨率的图片
- 根据设备屏幕尺寸自动选择合适的图片

**代码示例**：
```html
<img 
  src="small.jpg" 
  srcset="small.jpg 400w, medium.jpg 800w, large.jpg 1200w" 
  sizes="(max-width: 600px) 400px, (max-width: 1200px) 800px, 1200px"
  alt="Description"
>
```

## 2. 资源文件优化方案

### 2.1 CSS 优化

**具体措施**：
- 移除未使用的 CSS 代码
- 合并 CSS 文件，减少 HTTP 请求
- 进一步压缩 CSS 文件
- 使用 CSS 预处理器的高级特性减少代码量

**工具推荐**：
- PurgeCSS：移除未使用的 CSS
- cssnano：压缩 CSS 文件

### 2.2 JavaScript 优化

**具体措施**：
- 移除未使用的 JavaScript 代码
- 合并和压缩 JS 文件
- 实现代码分割，按需加载
- 优化 DOM 操作，减少重排和重绘

**工具推荐**：
- Terser：压缩 JavaScript 文件
- Webpack：实现代码分割和打包

### 2.3 字体优化

**具体措施**：
- 使用字体子集，只包含必要的字符
- 实现字体预加载和异步加载
- 考虑使用系统字体或 Google Fonts

**代码示例**：
```html
<!-- 字体预加载 -->
<link rel="preload" href="fonts/font.woff2" as="font" type="font/woff2" crossorigin>

<!-- 异步加载字体 -->
<link rel="stylesheet" href="fonts.css" media="print" onload="this.media='all'">
```

## 3. 加载策略优化方案

### 3.1 资源加载顺序

**具体措施**：
- 优化 CSS 和 JS 的加载顺序
- 关键 CSS 内联到 HTML 中，减少首屏渲染时间
- 非关键 CSS 异步加载
- 非关键 JS 使用 `defer` 或 `async` 属性延迟加载

**代码示例**：
```html
<!-- 内联关键 CSS -->
<style>
  /* 关键 CSS 代码 */
</style>

<!-- 异步加载非关键 CSS -->
<link rel="stylesheet" href="non-critical.css" media="print" onload="this.media='all'">

<!-- 延迟加载 JS -->
<script src="script.js" defer></script>
```

### 3.2 缓存策略

**具体措施**：
- 优化 Service Worker 缓存策略
- 设置合理的 HTTP 缓存头
- 使用内容哈希命名资源文件，实现长期缓存

**Service Worker 优化**：
- 缓存静态资源
- 动态内容使用网络优先策略
- 定期更新缓存

### 3.3 CDN 加速

**具体措施**：
- 使用 CDN 分发静态资源
- 配置 CDN 缓存策略
- 选择全球覆盖范围广的 CDN 服务

**推荐 CDN 服务**：
- Cloudflare
- jsDelivr
- UNPKG

**配置示例**：
在 `_config.shoka.yml` 中设置 CDN 地址：
```yaml
statics: https://cdn.jsdelivr.net/gh/californiafinch/californiafinch.github.io@latest/
```

## 4. 第三方服务优化方案

### 4.1 Algolia 搜索优化

**具体措施**：
- 优化搜索索引配置，减少索引大小
- 实现搜索功能的懒加载，只有在用户点击搜索框时才加载
- 合理设置搜索结果数量和分页

**代码示例**：
```javascript
// 懒加载 Algolia 搜索
const searchButton = document.querySelector('.search-button');
searchButton.addEventListener('click', () => {
  // 动态加载 Algolia 脚本
  const script = document.createElement('script');
  script.src = 'https://cdn.jsdelivr.net/npm/algoliasearch@4/dist/algoliasearch.umd.min.js';
  script.onload = () => {
    // 初始化搜索
    initSearch();
  };
  document.head.appendChild(script);
});
```

### 4.2 Valine 评论优化

**具体措施**：
- 实现评论功能的懒加载，只有在用户滚动到评论区时才加载
- 优化评论加载时机，避免阻塞页面渲染
- 合理设置评论分页和加载数量

**代码示例**：
```javascript
// 懒加载 Valine 评论
const commentSection = document.querySelector('#comments');
const commentObserver = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      // 动态加载 Valine 脚本
      const script = document.createElement('script');
      script.src = 'https://cdn.jsdelivr.net/npm/valine@1.4.14/dist/Valine.min.js';
      script.onload = () => {
        // 初始化评论
        new Valine({
          el: '#comments',
          appId: 'your-app-id',
          appKey: 'your-app-key'
        });
      };
      document.head.appendChild(script);
      commentObserver.unobserve(commentSection);
    }
  });
});

commentObserver.observe(commentSection);
```

## 7. 验证方法

### 7.1 性能测试工具

- **Lighthouse**：Google 开发的网站性能测试工具
- **WebPageTest**：详细的网站性能测试
- **Chrome DevTools**：实时分析网站性能

### 7.2 关键性能指标

- **First Contentful Paint (FCP)**：首次内容绘制时间
- **Largest Contentful Paint (LCP)**：最大内容绘制时间
- **Cumulative Layout Shift (CLS)**：累积布局偏移
- **Time to Interactive (TTI)**：可交互时间
- **Total Blocking Time (TBT)**：总阻塞时间

### 7.3 验证流程

1. **基线测试**：在优化前进行性能测试，记录关键指标
2. **实施优化**：按照优化方案实施各项措施
3. **验证测试**：在优化后进行性能测试，比较关键指标
4. **持续监控**：定期进行性能测试，确保优化效果持续
